# Mila 1.9.7-beta.1

**New**

- **Share a recording with another Mila user.** Right-click a recording and choose "Share Recording…" to export it as a single `.milashare` file carrying the audio, transcript, speaker names, summary, action items and, if voice recognition is on, the speakers' voice profiles. The recipient double-clicks or drops the file onto Mila and confirms what gets imported. Nothing has to be re-transcribed or re-named. Contributed by Daniel Solomon (@DanielSolomon).
- **Record now, transcribe after the call.** A new "Transcribe while recording" switch in Settings → Audio (on by default) lets you turn off live transcription, live speaker labels and Live AI for the duration of a call so Mila stays off the CPU; the recording is transcribed in the background once you stop. You can also stop a running transcription from the queue and run it later without losing the recording. Contributed by Ori Seri (@oriser).
- **Choose the summary language per recording.** The AI summary and action items can now be regenerated in English or Hebrew for a single recording from its context menu, the detail view or the rename sheet, overriding the global Output language in Settings → AI Features. An English summary of a Hebrew recording now renders left-to-right. Contributed by Daniel Solomon (@DanielSolomon).
- **The Record button shows "Starting…" while the microphone comes up.** With AirPods on macOS 27 the microphone can take several seconds to start; the button now shows that it is working instead of looking idle, and a second click no longer starts a second capture.
- **Claude can get timestamped transcripts from Mila.** The `mila-mcp` helper's `get_transcript` tool accepts `format: "srt"`, so a Claude session can produce subtitles or answer "when was that said". Contributed by Daniel Solomon (@DanielSolomon).

**Fixes**

- **No more crash when quitting during a remote transcription.** Quitting while a recording was uploading to a remote transcription server could abort Mila. Uploads are now cancelled cleanly on quit and the unfinished recording is picked up again on the next launch. Contributed by @noamleibovitch.
